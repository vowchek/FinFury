# AGENTS.md

Правила для агентов и разработчиков, работающих в этом репозитории.

## Общие принципы

- Проект — личные финансы (fintech). Данные пользователей чувствительны: **никогда** не хардкодь секреты/ключи API, не логируй чувствительные поля (пароли, токены, полные номера счетов).
- Чини причину, а не симптом. Изменения минимальны и в стиле существующего кода.
- Не трогай то, что не относится к задаче.
- Учитывай стыковку фронта, бэкенда и БД (контракты API, типы, модели БД).

## Архитектурные решения

- Ключевые решения зафиксированы в [docs/decisions](docs/decisions) (ADR). Перед изменением значимого решения — прочитай соответствующий ADR; при изменении решения напиши новый ADR, который ссылается на старый (не редактируй историю).
- **Единая транзакционная книга** (ADR-003): все позиции выводятся из транзакций. Snapshot-ввод конвертируется в opening-транзакцию. Не вводи параллельную «позиционную» модель.
- **Доходы** (ADR-006): дивиденды/купоны — это income events, а не только денежные операции.
- **Цены** (ADR-005): обращение к внешним источникам только через PriceProvider (абстракция + адаптеры + кэш), никогда напрямую из бизнес-логики.

## Стек и конвенции

- TypeScript-монорепо (React + NestJS), PostgreSQL + Prisma. Подробности — в ADR-001/002.
- Деньги хранить как целые числа в минимальных единицах (копейки/сатоши) или DECIMAL — не `float`. См. ADR-002.
- Валюты: все суммы сопровождаются кодом валюты (ISO 4217). Пересчёт — только через явный FX-курс.

## Проверка перед сдачей

- Запускай сборку/тесты/линт, если они есть. Если не запускал — честно назови причину.
- Не выдавай сделанное за проверенное.
