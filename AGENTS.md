# AGENTS.md

Правила для агентов и разработчиков в этом репозитории.

## Общие принципы

- Проект — личные финансы (fintech). Данные чувствительны: **никогда** не хардкодь секреты/ключи API, не логируй пароли, токены, полные номера счетов.
- Чини причину, а не симптом. Изменения минимальны и в стиле существующего кода.
- Не трогай то, что не относится к задаче.
- Учитывай стыковку фронта, бэкенда и БД (контракты API, типы, модели).

## Проверка перед сдачей

- **Обязательно** `pnpm test` по завершении задачи.
- Если затронуты типы/сборка — ещё `pnpm typecheck` и `pnpm build`.
- **Обязательно запусти проект** с изменениями (см. «Перезапуск» ниже):
  - ошибки старта — чини, пока поднимается чисто;
  - dev-серверы / docker — **фоном**;
  - занятые порты — заверши процессы и запускай заново.
- Не запускал проверку — честно скажи. Не выдавай сделанное за проверенное.

## Перезапуск проекта: порты и процессы

| Сервис | Порт |
|---|---|
| API (NestJS) | `3000` |
| Web (Vite) | `5173` / `5174` |
| PostgreSQL (docker) | `5432` |

1. Останови старые dev-процессы.
2. Освободи порты:
   - Windows: `netstat -ano | findstr :3000` (и `:5173`, `:5174`, `:5432`) → `taskkill /PID <pid> /F`.
   - Linux/macOS: `lsof -i :3000` → `kill -9 <pid>`.
3. PostgreSQL: `pnpm db:up` (при проблемах — `pnpm db:down`, снова `pnpm db:up`).
4. `pnpm dev` (или `dev:api` / `dev:web`) — **в фоне**.
5. Ошибки старта — чини и перезапускай.

Если агент поднял dev-серверы — в конце скажи порты и как остановить. Оставляй работать только если пользователю нужна проверка; иначе останови.
