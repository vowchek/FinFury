# Дорожная карта

## MVP (фаза 1) — ядро

Цель: рабочий цикл «ввёл транзакции → вижу портфель и стоимость».

- [ ] Монорепо (pnpm + turborepo), скелеты `apps/web` (Vite) и `apps/api` (NestJS).
- [ ] Auth: регистрация/вход/refresh (ADR-004).
- [ ] Справочник активов + PriceProvider с кэшем (ADR-005).
- [ ] Единая книга транзакций: ручной режим B (ADR-003).
- [ ] Позиции (производные) и оценка стоимости.
- [ ] Расходы и категории.
- [ ] «Узкий» банковский UI: дашборд, позиции, транзакции.

## Фаза 2 — существующий портфель и доходы

- [ ] Ручной режим A: snapshot-ввод → opening-транзакции (ADR-003).
- [ ] Доходы: дивиденды/купоны как income events (ADR-006), налоги, DRIP.
- [ ] Cost basis по партиям (FIFO/AVCO), реализованная/нереализованная прибыль.
- [ ] Графики стоимости и доходности.

## Фаза 3 — автоматический режим

- [ ] Импорт отчётов (CSV/XML): нормализация, предпросмотр, идемпотентность.
- [ ] Интеграции с API брокеров (по востребованности): Tinkoff, IB, Binance и др.
- [ ] Фоновые задачи: обновление цен, синхронизация.

## Фаза 4 — расширение

- [ ] Бюджетирование и аналитика расходов.
- [ ] Мультивалютные портфели и FX-пересчёт.
- [ ] Уведомления (дивиденды, цели).
- [ ] Экспорт данных, отчёты.

## Приоритеты и принципы

- Сначала **ядро книги** (фаза 1) — на нём строится всё остальное.
- Доходы и snapshot-режим — сразу после ядра (фаза 2).
- Авто-импорт — после того как ручной учёт стабилен (фаза 3).
- Каждая фаза заканчивается проверяемым результатом (сборка + тесты).
