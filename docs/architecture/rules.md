# Правила денег и учёта

> Пять идей простыми словами. Всё остальное в docs ссылается сюда — не копируйте список.

## 1. Правда — в дневнике сделок

Мы не храним «сколько акций у тебя» как главную правду. Главное — список покупок и продаж (**транзакционная книга**). Позиция — это итог дневника, как сумма в тетради.

См. [ADR-003](../decisions/ADR-003-transaction-ledger.md).

## 2. Деньги — целые копейки, не дроби

Суммы хранятся целыми числами в минимальных единицах + код валюты.  
Пример: `12345` + `RUB` = 123.45 ₽.  
`float` для денег запрещён — он врёт при округлении.

См. [ADR-002](../decisions/ADR-002-database.md).

## 3. Цены — только через «окошко»

Бизнес-код не ходит в биржи напрямую. Всё через **PriceProvider** (адаптеры + кэш). Курсы валют — отдельно, mid-rate (CBR / Frankfurter).

См. [ADR-005](../decisions/ADR-005-price-provider.md), [ADR-009](../decisions/ADR-009-fx-rates.md).

## 4. Каждый видит только своё

Все запросы режутся по `userId` из токена. Чужой счёт → 404, не «пустой список для хакера».

См. [ADR-004](../decisions/ADR-004-auth.md).

## 5. Прибыль от продаж — по партиям

Покупки складываются в **партии** (как пачки с датой). При продаже списываем старейшие сначала (**FIFO**). Так считается реализованная прибыль.

Средняя цена позиции (**AVCO**) — для «во сколько обошлись оставшиеся бумаги».

## Бонусом

| Тема | Правило |
|---|---|
| Дивиденды / купоны | Отдельные **income events**, не только строка в книге ([ADR-006](../decisions/ADR-006-income-events.md)) |
| Валюта на дашборде | Переключатель `displayCurrency`; счета остаются в своей валюте |
| Импорт | Повтор не создаёт дубли: уникальный `(source, sourceId)` |
