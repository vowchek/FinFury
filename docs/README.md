# Документация FinFury

> Одна карта: что это, как устроено, куда смотреть дальше.

FinFury — личный учёт инвестиций. Ты записываешь покупки и продажи; программа сама считает, сколько чего у тебя и сколько это стоит сейчас.

## Порядок чтения

1. [Правила денег и учёта](architecture/rules.md) — пять идей, на которых держится всё.
2. [Сущности](architecture/domain-model.md) — кто есть кто (счёт, актив, транзакция…).
3. [Как вводить данные](architecture/data-entry-modes.md) — с нуля, снапшотом или (позже) импортом.
4. [Функции](features/README.md) — как это работает в коде и в UI.
5. [API](api/contract.md) или [ADR](decisions/README.md) — справочник маршрутов и «почему так».

Запуск проекта — в [корневом README](../README.md).
