# Счета и активы

> Счета — твои «папки» с валютой. Активы — общий справочник бумаг и монет.

Модули: `accounts/`, `assets/`. Маршруты — [контракт API](../api/contract.md).

## Суть

**Счёт** принадлежит пользователю: брокер / крипто-кошелёк / кэш.  
**WALLET** — только валюта USD (иначе 400).

**Актив** общий для всех: цены и дивиденды одни. В UI вручную не создаёшь — выбираешь из поиска; при выборе с внешнего API актив появляется в справочнике.

**ExternalAsset** — кэш внешнего поиска, не замена справочника.

## Как это работает

- Счета: CRUD с изоляцией по `userId`; удаление каскадом.
- Поиск: `GET /assets?q=` — локально; `GET /assets/external` — MOEX/Yahoo/CoinGecko по типу счёта (мин. 2 символа).
- BROKER → акции/облигации/фонды; WALLET → крипта; CASH → пусто.

На дашборде карточки счетов показывают суммы в **валюте счёта** (не в display currency портфеля).
