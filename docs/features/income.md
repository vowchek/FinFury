# Доходы

> Дивиденд — не просто «плюс кэш», а событие с датой выплаты, налогом и опцией реинвеста.

Модуль: `apps/api/src/modules/income/`. Решение — [ADR-006](../decisions/ADR-006-income-events.md).  
Маршруты — [контракт API](../api/contract.md).

## Суть

Создаёшь **income event**: тип, актив, `paymentDate`, gross, налог.  
Сервер считает `net = gross − taxWithheld` (клиенту не доверяем).

По умолчанию в книгу пишется транзакция `income` на net → растёт **кэш** счёта (не «взносы»).

**`distributed: true`:** только событие (прибыль позиции / статистика), без `income`-транзакции — кэш не меняется. Так вводится накопленный доход в снапшоте «+ Позиции».

**DRIP:** ещё и `buy` на net → кэш ≈ 0, растут позиции и партии.

## Как это работает

- Список и фильтры по счёту / активу / датам.
- Статистика: итоги, по месяцам, по активам; `yieldPct` ≈ net / текущая себестоимость позиции.
- Связь `transactionId` без жёсткого FK: удалили tx — событие остаётся.
